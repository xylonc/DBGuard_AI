--- backend/app/services/fix_unit_render.py (122 lines) ---

Function: render_action(action: dict) -> list[str]
  Renders a typed action to SQL statements
  Input: {"action": "set_config", "param": <name>, "value": <str>}
        or {"action": "reset_config", "param": <name>}
  Output: List of SQL statements WITHOUT trailing semicolons
          Order: ALTER SYSTEM statement first, then pg_reload_conf()
  Example: ["ALTER SYSTEM SET log_connections = 'on'", "SELECT pg_reload_conf()"]

Function: derive_rollback(prior_state: dict, apply_action: dict) -> dict
  Computes the rollback action needed to restore prior_state
  Input: prior_state (dict with value, sourcefile), apply_action (dict with action, param)
  Output: rollback action dict
  Logic:
    - apply set_config, prior from auto.conf -> set_config(param, prior.value)
    - apply set_config, prior from other/null -> reset_config(param)
    - apply reset_config, prior from auto.conf -> set_config(param, prior.value)
    - apply reset_config, otherwise -> raises ValueError
